# Hasan Services Website

## Client
Personal / Side project for Hasan Jahoush.

## Project Type
Full project: convert an existing static personal portfolio into a service-led business website with a clear path to Handoff.

## What We're Building
A service website that sells Hasan's AI, web design, SEO, automation, and backend engineering services to small businesses and local operators, using Qualia Solutions as a reference for service positioning and premium dark technical energy.

## Core Value
Visitors should understand within five seconds what services Hasan offers, what business problems those services solve, and how to book a consultation.

## Requirements
- [ ] REQ-001: Reposition the homepage from "about Hasan" to "services businesses can buy."
- [ ] REQ-002: Present AI agents, business automation, web design, SEO, and backend systems as clear service offerings.
- [ ] REQ-003: Add strong conversion paths: consultation CTA, WhatsApp, email, and service inquiry routes.
- [ ] REQ-004: Preserve credible personal proof: experience, Cyprus location, selected projects, and technical stack.
- [ ] REQ-005: Improve SEO metadata and structured data from `Person`-only to service/business intent.
- [ ] REQ-006: Keep the current static hosting path simple unless the project later needs CMS, forms, or backend integration.
- [ ] REQ-007: Verify responsive layout at mobile, tablet, and desktop before shipping.

## Out of Scope
- Full SaaS application.
- Supabase backend or authentication unless a later phase adds real lead capture storage.
- Copying Qualia Solutions assets, wording, or brand identity directly.
- Long blog publishing system in Milestone 1.

## Stack
Static HTML / CSS / JavaScript, Bootstrap 5, Font Awesome, hosted as a static site. Future optional path: Next.js + Vercel if the site needs CMS, forms, analytics, or experiments.

## Design Direction
Premium service-tech site: dark, focused, high-contrast, atmospheric, and conversion-led. Use Qualia Solutions as a positioning and interaction reference, but create an independent Hasan service brand.

## Decisions
| Decision | Why |
|----------|-----|
| Treat this as a services business site, not a personal portfolio | The user's current goal is to sell services, not describe themselves. |
| Keep Milestone 1 static | The existing site is static and the MVP can demonstrate the new positioning without a framework migration. |
| Use Qualia Solutions as reference, not source | It gives service structure and tone, but Hasan's site needs its own brand and copy. |
