# Research — Pitfalls

## Positioning Pitfalls
- Keeping "Hi, I'm Hasan" as the hero after deciding the site should sell services.
- Listing technologies before business outcomes.
- Calling everything a skill instead of packaging services clients can buy.
- Copying Qualia Solutions too closely instead of using it as a structural reference.

## Design Pitfalls
- Over-indexing on "crazy design" while weakening trust.
- Using generic neon AI visuals without service clarity.
- Letting the hero become too tall or clipped on laptop screens.
- Hiding the CTA on mobile.

## Implementation Pitfalls
- Adding more CSS overrides without deleting obsolete portfolio styles.
- Updating visible copy but leaving SEO/structured data as personal-only.
- Treating project screenshots as proof without explaining business value.
- Shipping without checking mobile and desktop screenshots.

## Verification Pitfalls
- Curl-only checks are insufficient. Use a browser screenshot and console check.
- Validate that every nav link lands on a real section.
- Validate contact links and downloadable CV paths.
