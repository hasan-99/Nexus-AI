Hasan Social Publisher

A personal content studio that helps Hasan Jahoush prepare LinkedIn posts and schedule them to his own profile. It runs on his Windows computer and is not offered as a public service or to other users.

What it does

The tool stores profile settings, post drafts, locally rendered post images, schedules, and publishing history in a local SQLite database and files. A local n8n workflow calls the dashboard on the same computer to generate and publish scheduled content.

When enabled, it can publish text and image posts to Hasan’s personal LinkedIn profile without a per-post approval step. Its image posts use branded graphics rendered locally from the post text and visual brief.

Connected services and data

ChatGPT plan usage may send the configured profile, topic, recent post excerpts, and selected public-source excerpts to OpenAI to generate post copy. This uses the separately authorized ChatGPT plan allowance, not an OpenAI API key or paid API fallback. See the privacy notice.

Google OAuth requests the Gmail send permission only. The tool uses it to send publishing and failure notifications to Hasan’s configured address; it does not read the Gmail inbox. LinkedIn OAuth is used to identify Hasan’s profile and publish the content he has configured.
